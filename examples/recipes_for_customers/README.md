### Create Customers Table
```shell
tablepilot create examples/recipes_for_customers/customers.json
```

### Generate Data for Customers Table
```shell
tablepilot generate customers -c=30 -b=30
```

### Create Recipes Table
```shell
tablepilot create examples/recipes_for_customers/recipes.json
```


### Generate Data for Recipes Table
```shell
tablepilot generate recipes -c=30 -b=5
```
